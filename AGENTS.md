# Dragon Rider — Project Instructions

- Build a cinematic, realistic Viking fantasy action-adventure in Unreal Engine 5. Dragon flight is the central gameplay experience.
- Preserve the visual ambition of the project references while building the actual game in manageable stages. Do not lock in the story prematurely.
- Guide the owner as a beginner. Explain the next step clearly and distinguish work that needs the Windows Unreal desktop from work suitable for Codex Cloud.
- Before project work, inspect the existing files and read notes/handoff.md if present, CLAUDE.md if present, and all applicable AGENTS.md instructions.
- Use a focused codex/<task> branch. Keep changes focused, commit working steps, and update notes/handoff.md.
- Do not overwrite or delete existing work, push, merge, spend money, or make a major architecture decision without the owner's permission.
- Do not claim anything was installed, created, tested, or completed unless it was verified.
- Prioritize the playable flight foundation: mounting, takeoff, steering, speed and altitude control, dives and pull-ups, aerial maneuvers, and a comfortable flight camera.
- Keep Unreal-generated files out of Git. Check Git LFS availability and storage implications before adding large binary assets; do not incur costs without permission.
